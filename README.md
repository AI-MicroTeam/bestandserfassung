# Bestandserfassung

Werkzeug zum Erfassen von Laborbestand am Handy: Lagerort, Foto, Gruppe, Bezeichnung.
Die Seite laeuft vollstaendig im Browser. Erfasste Daten und Fotos bleiben auf dem
Geraet, bis die Datei von Hand weitergegeben wird - diese Seite sendet nichts.

Seite: https://ai-microteam.github.io/bestandserfassung/

Die Dateien hier werden erzeugt. Quelle und Bau liegen im Laborsystem
(`bau_bestandserfassung.py --veroeffentlichen`); Aenderungen bitte dort.
